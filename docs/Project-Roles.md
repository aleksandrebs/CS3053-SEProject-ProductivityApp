## Team Roles & Responsibilities

| Role | Team Member | Responsibilities | Deliverables |
|---|---|---|---|
| **Product Owner** | Sashka | Defines product vision, represents team and users, prioritizes and grooms the backlog, writes/refines user stories, accepts completed stories, communicates with stakeholders | Product overview, MVP scope, roadmap, prioritized backlog, user stories, sprint acceptance sign-off |
| **Scrum Master** | Madi | Facilitates sprint planning, daily standups, sprint reviews, and retrospectives; removes blockers; tracks sprint progress; enforces Agile process and team cadence | Sprint plans, burndown/velocity tracking, retrospective notes, meeting facilitation, process documentation |
| **DevOps Engineer** | You | Sets up and maintains CI/CD pipelines, manages environments (dev/staging/prod), configures FastAPI deployment, handles PostgreSQL database provisioning and migrations (via SQLAlchemy), monitors app health and logging | CI/CD pipeline config, deployment scripts, environment setup docs, database migration scripts, monitoring/logging setup |
| **DevOps Engineer** | Vlad | Manages source control workflow (branching, PR reviews, merge policies), containerization (Docker), infrastructure as needed, backend API integration support (FastAPI + SQLAlchemy), security/config management | Repo branching strategy, Dockerfiles/compose configs, PR/code review checklist, backend integration testing, secrets/config management docs |
